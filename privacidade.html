Política de Privacidade

Última atualização:

1. Dados Recolhidos

Para o funcionamento do serviço, recolhemos: token de acesso (para autenticação), subscrição de notificações push (endpoint técnico), watchlist (lista de ativos escolhidos) e histórico de sinais recebidos. Não recolhemos dados bancários, senhas de corretoras nem documentos pessoais.

2. Uso dos Dados

Os dados são utilizados exclusivamente para: autenticar o seu acesso, enviar notificações push de sinais em tempo real, guardar as suas preferências entre sessões e mostrar o histórico de sinais no painel.

3. Onde os Dados Ficam Armazenados

Utilizamos a infraestrutura Google Firebase (Firestore) para armazenamento seguro, com encriptação em trânsito (HTTPS) e em repouso.

4. Partilha de Dados

Não vendemos, alugamos nem partilhamos os seus dados pessoais com terceiros. Os dados são usados apenas internamente para o funcionamento do serviço.

5. Notificações Push

As notificações são enviadas via protocolo Web Push (VAPID). Pode desativá-las a qualquer momento nas configurações do dispositivo ou no menu da app.

6. Segurança

Todas as comunicações são encriptadas via HTTPS. Os tokens são armazenados em formato hash (SHA-256) nos servidores — nunca em texto simples.

7. Os Seus Direitos

Pode, a qualquer momento: terminar sessão e limpar dados locais; solicitar a remoção da conta e dados associados; desativar as notificações push.

8. Aviso Financeiro

O Trader BOT é uma ferramenta de análise técnica automatizada. Não constitui aconselhamento financeiro. Todas as decisões de investimento são da exclusiva responsabilidade do utilizador.

9. Contacto

Para questões sobre privacidade: traderbotanalyzer@zohomail.com

10. Alterações a Esta Política

Podemos atualizar esta política periodicamente. A data no topo será sempre a referência da última versão.
